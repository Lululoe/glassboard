The same five cards at three depths. Status colors (OK / warning / fail) stay fixed; everything else follows the accent. Back to all styles.

A · Skin

Monospace, square corners, flat, 1px outlines. Every component keeps its normal shape and works the same; only CSS tokens change.
  • Bars, graph, tiles, app grid unchanged — app icons become outlined letters
  • New cards get the look for free
Effort: ~1–2 days. No per-card work.

B · Hybrid

A, plus the shared components switch to text: bars as ████░░, graphs as block characters, toggles as [x], status as [ OK ], apps as a status list.
  • Only shared components (UsageBar, StatusPill, graph, tile, app grid) need a text variant
  • Cards keep their layout and interaction
Effort: ~4–6 days. Small per-component cost later.

C · Full ASCII

Each card is drawn as text inside a box-drawing frame, with ASCII-art weather, an axis-labelled block chart, a shell prompt, and optional scanlines / glow / flicker.
  • Most striking, but every card needs its own text renderer
  • Frames must be sized in characters, so cards snap to a character grid; clicks and editing need extra care
Effort: ~2–3 weeks, plus a text renderer for every future card.
